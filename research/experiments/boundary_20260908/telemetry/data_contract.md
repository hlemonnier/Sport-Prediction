# Original-issuance telemetry assembly contract

Declared before historical telemetry construction. The only forecast horizon is the frozen `frontier_20260907.live_frontier.enrich` completed-lap issuance. The 44 discovery races contain 39,220 original issuances and 38,370 matched next-eligible-lap targets; all 850 unmatched forecasts remain explicit. The matched-only `discovery_data.pkl` is a parity reference, never an issuance source.

`read_laps(path)` returns the original `pandas.read_csv` frame and an exact clock index keyed by normalized driver and observed lap. It separately reads the original `Time` CSV text and converts decimal seconds to an integer number of nanoseconds. Values must be finite, nonnegative and exactly representable in integral nanoseconds; no rounding, millisecond truncation, source `Utc`, or estimated session origin is used. The original float `issued_at_timestamp` stays untouched. The exact clock is an added field; it does not alter incumbent features or join keys.

`build_event(raw, event_key, clocks, telemetry_path, ...)` returns `EventFeatures.frames_by_lag`, a dictionary keyed by the fixed integer lags 0 and 2. Each flat frame retains every original issuance, every original column, the exact ordered 80 baseline features and `forecast_naive_seconds`. Additions are `year`, `issuance_id`, `issued_at_ns`, `telemetry_lag_seconds`, `telemetry_cutoff_ns`, `telemetry_source_status`, `telemetry_supported`, `telemetry_values` (90 ordered numbers), and `telemetry_provenance`. The source row identity is provenance, not a model feature. Each lag has a separate cursor. Queries are globally sorted by exact cutoff and allow equal-cutoff drivers. Inclusion is strictly `packet.available_ms * 1_000_000 < cutoff_ns`, where `cutoff_ns = issued_at_ns - lag * 1_000_000_000`. Negative cutoffs remain unsupported without payload reads.

An explicitly unavailable acquisition retains all original forecasts with the encoder's exact empty-window values and false support; its row status is `unavailable`. A downloaded source retains row status `downloaded` while features are constructed; this is not a claim of full-stream integrity. A separate exhaustive validation must pass after feature closure and before labels/fitting. A malformed download produces `invalid_downloaded_input`, preserves already-written feature ledgers, and aborts. A late corruption never retroactively replaces earlier forecasts with unavailable-source fallback.

The feature builder discards both the frozen helper's internally returned matched table and all target fields. Future lap values can be processed later as ordinary observations, but neither their matches nor their values are supplied to an earlier telemetry query. No S1/S2 checkpoints, canonical position interpolation, future tyre information, or changes to the incumbent's clean-lap rules are introduced.

The original research `enrich` helper lacks an empty matched-table schema at a first issuance with no later target. Only that proven zero-match case uses the already published `feature_encoder.observed_features` equivalent, retaining those unmatched issuances. Zero-issuance warmup prefixes get an empty fixed feature schema. Other failures propagate; the frozen sources are unchanged.

`close_features(...)` writes each target-free frame exclusively and closes a separate hash-bound feature receipt, including the immutable design-lock hash, raw source hashes, exact baseline feature order, telemetry feature order, all row identities, and per-event counts. `attach_labels(...)` requires that receipt and rechecks its files before recomputing the original matching relation. It writes a separate all-issuance label ledger with `outcome_status` exactly `matched` or `unmatched`. Matched records preserve `target_lap_number`, original float `target_timestamp`, `lap_time_seconds`, and `target_same_stint`, plus exact `target_at_ns` and `target_id = event/driver/target_lap`. Every unmatched target field is null. It never overwrites or shrinks feature files. Both lag tables must have identical original columns and issuance populations.

The orchestration layer owns source/spec freezing and the 44-event acquisition manifest. This module has no fitting or scoring entry point and must not construct historical telemetry features until that layer authorizes the closed design. Tests use synthetic lap frames and synthetic telemetry, including equal clocks, poisoned future values, delayed telemetry, empty warmup prefixes, exact incumbent parity, and explicit unmatched retention.

Archive-prefix clocks remain proxies for observed availability, not certified historical client receipt times. The original lap input contract and its existing limitations are inherited unchanged.
